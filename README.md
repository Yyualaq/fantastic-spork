# fantastic-spork

## Dark Souls - A Soul-like Game

A browser-based soul-like game featuring challenging combat, dodge mechanics, and the classic "YOU DIED" experience.

### Features

- **Dark, atmospheric aesthetic** - Classic soul-like visual style with golden accents
- **Combat system** - Attack enemies with timing-based combat
- **Dodge rolling** - Stamina-based dodge mechanic with invulnerability frames
- **Enemy AI** - Enemies that chase and attack the player
- **Health & Stamina** - Resource management system
- **Death mechanics** - Lose your souls on death and respawn at bonfire
- **Soul collection** - Defeat enemies to earn souls

### How to Play

1. Open `index.html` in a web browser
2. Use the controls to fight enemies and survive

### Controls

- **WASD or Arrow Keys** - Move your character
- **Space** - Attack
- **Shift** - Dodge roll (costs stamina)

### Gameplay

Fight waves of enemies to collect souls. Be careful - if you die, you'll lose all your collected souls and respawn at the bonfire. Manage your stamina carefully, as dodge rolling is essential for survival but consumes stamina.

### Technologies

- Pure HTML5, CSS3, and JavaScript
- HTML5 Canvas for rendering
- No external dependencies required
